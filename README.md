# 🛡️ Operational Cyber Security & Threat Intel Repo

Questo repository ospita il codice e le sorgenti del portale di sicurezza di `mrbytehub.github.io`. Il focus è la centralizzazione e la semplificazione in formato *actionable* di bollettini tecnici e campagne di phishing attive.

## 🚀 Workflow di Pubblicazione
1. **Raccolta:** Monitoraggio dei feed ufficiali (ACN, CERT-AGID, D3Lab, NVD).
2. **Elaborazione:** Parsing e strutturazione tramite un **Custom Gemini Gem** per standardizzare il formato in Markdown di tipo "Ready-to-Patch".
3. **Validazione:** Revisione manuale e integrazione di query operative/comandi di remediation.
4. **Deploy:** Caricamento su GitHub Pages con compilazione automatica della Dashboard.
